# 🚀 My Koders Summer Bootcamp 2026 Journey

Welcome to my repository showcasing all the projects I built during the Koders Summer Bootcamp 2026. This collection represents my daily progress, learning journey, and practical projects completed throughout the bootcamp.

I participated in the Koders Summer Bootcamp 2026, where a new mission was released every day at 11:00 AM IST. Each mission challenged me to build practical web applications, learn new technologies, and improve my development skills.

## 🛠️ Technologies Used

Across all projects, we utilize modern web development technologies:

### Frontend Frameworks
- **Next.js** (App Router) - React framework for production applications
- **React 19** - UI library
- **TypeScript** - Type-safe JavaScript

### Styling
- **Tailwind CSS** - Utility-first CSS framework
- **CSS Modules** - Component-scoped styling

### UI Components
- **shadcn/ui** - Beautiful, accessible UI components
- **Lucide React** - Modern icon library
- **Sonner** - Toast notifications

### Tools & Libraries
- **Vite** - Build tool and dev server
- **ESLint** - Code linting
- **Prettier** - Code formatting

### APIs & Services
- **Quote APIs** (ZenQuotes, QuotesDB, QuoteSlate)
- **Exchange Rate API** - Real-time currency conversion
- **Weather APIs** - Weather data

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn package manager
- Git

### Clone the Repository

```bash
git clone https://github.com/Krish-vadsak45/Koders_Summer_Bootcamp.git
cd Summer-Bootcamp
```

### Running Individual Projects

Each project is self-contained. Navigate to any project directory and follow its specific README:

```bash
cd 01_Simple_Digital_Clock  # or any other project
npm install
npm run dev
```

### Project-Specific Setup

Each project has its own `README.md` with detailed setup instructions, features, and deployment guides. Please refer to the individual project READMEs for:

- Detailed feature descriptions
- Project-specific dependencies
- Local setup instructions
- Deployment guides
- Screenshots and demos

**Tech:** Next.js, TypeScript, Tailwind CSS, shadcn/ui, Sonner
